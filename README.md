# TTK CORP — Telegram Support Bot

Telegram-бот поддержки с веб-панелью для операторов. Пользователи пишут боту в Telegram, а операторы отвечают им из браузера: с историей чатов, медиа и стикерами.

## Возможности

- Чаты с пользователями Telegram в веб-панели
- Приём и отправка медиа (фото, видео, GIF, документы)
- Стикерпаки: создание, переименование, загрузка и удаление стикеров
- Авторизация операторов, роли `operator` и `admin`
- Управление операторами (для админа), профиль и смена пароля
- Статистика
- Настройки бота, включая автоответ
- Уведомления о новых сообщениях в панели

## Стек

Python 3.13, [aiogram](https://docs.aiogram.dev/), [Flask](https://flask.palletsprojects.com/), SQLite.

## Установка

1. Клонируйте репозиторий или скачайте архив из раздела [Releases](../../releases).
2. Установите зависимости:

   ```bash
   py -3.13 -m pip install -r requirements.txt
   ```

3. Создайте бота у [@BotFather](https://t.me/BotFather) и положите токен в файл `token.txt` в корне проекта (только токен, одной строкой).
4. Запустите:

   ```bash
   py -3.13 bot.py
   ```

5. Откройте http://127.0.0.1:5000. При первом запуске откроется страница `/setup`, где нужно создать администратора.

## Настройка

| Что | Как |
|---|---|
| Токен бота | Файл `token.txt` (обязателен) |
| Секретный ключ сессий | Переменная окружения `MIZU_SECRET_KEY` |
| Адрес и порт панели | Константы `WEB_HOST` и `WEB_PORT` в `bot.py` (по умолчанию `127.0.0.1:5000`) |

Если панель будет доступна не только с вашего компьютера, обязательно задайте свой `MIZU_SECRET_KEY`. Значение по умолчанию небезопасно.

PowerShell:

```powershell
$env:MIZU_SECRET_KEY = "длинная-случайная-строка"
py -3.13 bot.py
```

## Структура проекта

```
bot.py           — Telegram-бот и Flask-панель
templates/       — HTML-шаблоны
static/          — panel.js
requirements.txt
```

При работе автоматически создаются (и не попадают в git):

```
token.txt        — токен бота
support.db       — база данных SQLite
media/           — файлы из чатов
avatars/         — аватарки пользователей
stickers/        — стикерпаки
```

## Безопасность

- Никогда не публикуйте `token.txt` и `support.db`. Они указаны в `.gitignore`.
- Если токен попал в чужие руки, перевыпустите его через @BotFather командой `/revoke`.
- Пароли операторов хранятся в виде хешей PBKDF2-SHA256.
