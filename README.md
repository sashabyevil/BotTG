# TTK CORP — Telegram Support Bot

Telegram-бот поддержки с веб-панелью для операторов. Пользователи пишут боту в Telegram, а операторы отвечают им из браузера: с историей чатов, медиа и стикерами.

## Возможности

- Чаты с пользователями Telegram в веб-панели
- Приём и отправка медиа (фото, видео, GIF, документы)
- Стикерпаки: создание, переименование, загрузка и удаление стикеров
- Авторизация операторов, роли `operator` и `admin`
- Управление операторами (для админа), профиль и смена пароля
- Статистика
- Настройки бота, включая автоответ
- Уведомления о новых сообщениях в панели

## Стек

Python 3.13, [aiogram](https://docs.aiogram.dev/), [Flask](https://flask.palletsprojects.com/), SQLite.

## Установка

1. Клонируйте репозиторий или скачайте архив из раздела [Releases](../../releases).
2. Установите зависимости:

   ```bash
   py -3.13 -m pip install -r requirements.txt
   ```

3. Создайте бота у [@BotFather](https://t.me/BotFather) и положите токен в файл `token.txt` в корне проекта (только токен, одной строкой).
4. Запустите:

   ```bash
   py -3.13 bot.py
   ```

5. Откройте http://127.0.0.1:5000. При первом запуске откроется страница `/setup`, где нужно создать администратора.

## Настройка

| Что | Как |
|---|---|
| Токен бота | Файл `token.txt` (обязателен) |
| Сеть, HTTPS, открытие порта | Файл `server_config.json` (создаётся при первом запуске) |
| Ключ подписи сессий | Создаётся сам в `secret.key`, либо переменная окружения `MIZU_SECRET_KEY` |

## Доступ из интернета и HTTPS

По умолчанию панель доступна только на самом компьютере (`http://127.0.0.1:5000`). Всё остальное включается в `server_config.json`, после чего бота нужно перезапустить:

```json
{
    "public": true,
    "port": 5000,
    "https": true,
    "upnp": true,
    "firewall": true
}
```

| Параметр | Что делает |
|---|---|
| `public` | Панель слушает все сетевые адреса, а не только этот компьютер |
| `port` | Порт панели |
| `https` | Панель работает по `https://`. Сертификат создаётся сам (`cert.pem`, `key.pem`) |
| `cert_file`, `key_file` | Свои файлы сертификата, например от Let's Encrypt |
| `upnp` | Бот сам открывает порт на роутере через UPnP и закрывает при выходе |
| `external_port` | Порт снаружи, если он должен отличаться от `port` (`0` — такой же) |
| `firewall` | Добавляет правило в брандмауэр Windows (нужен запуск от администратора, один раз) |

Что важно знать:

- **Сначала создайте администратора локально.** Страница `/setup` открывается только с самого компьютера, а уже потом включайте `public`.
- **Самоподписанный сертификат** шифрует трафик, но браузер покажет предупреждение при первом входе. Чтобы его не было, нужен домен и настоящий сертификат: укажите его файлы в `cert_file` и `key_file`.
- **UPnP** работает, если он включён на роутере и у провайдера есть публичный («белый») IP. Если внешний адрес роутера не публичный, бот напишет об этом в консоли. Тогда порт придётся пробрасывать вручную или использовать VPN/туннель.
- На вход действует ограничение: 5 неверных попыток с одного IP, потом блокировка на 5 минут.
- Telegram-бот работает через polling, ему открытые порты не нужны. Порты нужны только для веб-панели.

## Структура проекта

```
bot.py           — Telegram-бот и Flask-панель
netsetup.py      — HTTPS, UPnP и правило брандмауэра
templates/       — HTML-шаблоны
static/          — panel.js
requirements.txt
```

При работе автоматически создаются (и не попадают в git):

```
token.txt        — токен бота
server_config.json — настройки сети
secret.key       — ключ сессий
cert.pem, key.pem — сертификат HTTPS
support.db       — база данных SQLite
media/           — файлы из чатов
avatars/         — аватарки пользователей
stickers/        — стикерпаки
```

## Безопасность

- Никогда не публикуйте `token.txt`, `support.db`, `secret.key` и `key.pem`. Они указаны в `.gitignore`.
- Если токен попал в чужие руки, перевыпустите его через @BotFather командой `/revoke`.
- Пароли операторов хранятся в виде хешей PBKDF2-SHA256.
